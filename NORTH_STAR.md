# Manifest North Star (Homebrew Tap)

Status: Active  
Repository role: package distribution layer

## Mission

Deliver reliable, low-friction installation and upgrade paths for Manifest CLI through Homebrew.

## Responsibilities

- Maintain `Formula/manifest.rb` with accurate source URL and checksum.
- Keep tap docs aligned with actual install/upgrade behavior.
- Minimize lag between CLI release availability and tap formula updates.

## Priorities

1. Release-to-formula update reliability.
2. Install/upgrade clarity for operators and developers.
3. Consistent version and source-of-truth messaging across docs.
